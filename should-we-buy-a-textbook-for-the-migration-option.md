# Should We Buy A Textbook For The Migration Option?

## Question

If the department switches fully in 2027, should we buy a board-endorsed Migration textbook for Key Stage 4 rather than relying on booklets?

## Status

Deferred until the April 2027 decision ([[should-the-whole-department-switch-to-migration-in-2027]]). No endorsed textbook for the revised specification had been announced as of October 2026.

## Thinking so far

At Key Stage 4 my view differs from Key Stage 3 ([[booklets-beat-textbooks-at-ks3]]): pupils revise from textbooks at home, and an endorsed book matches the board's language. Booklets would remain the teaching material. Budget would be about 25 GBP a copy for around 150 pupils.
