# Levels-Based Mark Scheme

A holistic way of marking extended answers: the marker reads the whole answer, decides which level description fits best, then places it within that level's mark range. It is the opposite of point marking, where marks are added up for each correct idea.

## The trap

Markers used to point marking drift into adding up knowledge inside a levels scheme. A long, accurate, one-sided answer then climbs into a level it cannot reach, because the level descriptor is about argument, not knowledge. That is exactly what the [[mock-moderation-2025-12-10|December 2025 moderation]] found: 9 of 12 scripts a level too high.

## How I mark now

1. Read the whole answer before writing anything.
2. Ask the level question first: one side, two sides, judgement?
3. Only then decide the mark within the level, using knowledge and precision.
4. Check against an exemplar at the same level ([[merrow-exemplar-scripts-2025]]).
