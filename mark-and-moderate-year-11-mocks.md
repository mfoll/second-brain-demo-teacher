# Mark And Moderate Year 11 Mocks

My routine for each Year 11 mock round, following the department's [[department-moderation-protocol]]. It exists because of the [[mock-moderation-2025-12-10|December 2025 moderation]].

## Before marking

1. Read the latest Merrow examiners' report section for each question set ([[merrow-examiners-report-summer-2026]]).
2. Re-read the [[merrow-levels-mark-scheme-16-mark-question]] and its red annotation: one-sided answers stay in Level 2.
3. Department standardisation: each marker marks two [[merrow-exemplar-scripts-2025|board exemplars]] blind, then compares with the board's marks. Do not start until within one mark.

## Marking

4. Mark the 16-mark answers across all scripts in one sitting, not script by script, so the standard does not drift. Level first, then mark ([[levels-based-mark-scheme]]).
5. Mark the other questions script by script.
6. Record marks in Ledgerwise; class distribution only in the vault.

## Moderation

7. Pass 10% of scripts, chosen across the range, to a colleague for [[blind-double-marking]] on copies with marks covered.
8. Differences above two marks on a 16-mark answer go to Ruth as third reader.
9. Send the moderation sample to Kittow when a swap is scheduled ([[vikram-iyer]]).

## After

10. Grades to pupils as ranges ([[mock-grades-should-be-reported-as-ranges]]).
11. Write the whole-class feedback sheet ([[run-whole-class-feedback]]).
12. Note anything about access arrangements use for Sian, directly, not here.

## Do not

Put scripts or extracts into any AI tool until the trust approves one ([[can-we-use-ai-to-draft-feedback-on-mock-essays]]).
